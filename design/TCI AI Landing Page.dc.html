01 · FLAGSHIP

Agentic Workspace

พื้นที่ทำงานส่วนตัวของนักวิจัยแต่ละคน รวม Research Assistant, Deep Research และเครื่องมือทั้งหมดไว้ที่เดียว พร้อมไฟล์ต้นฉบับและประวัติการทำงาน AI Agent จะเลือกเรียก Skill และ MCP ที่เหมาะสม เช่น ThaiJO Search, Article, Journal, Author และ Citation MCP ผ่าน TCI MCP Gateway โดยอัตโนมัติ และจดจำบริบทงานวิจัยของคุณไว้ตลอด

  • ขับเคลื่อนด้วย AI Agent: วางแผน → มอบงานให้ Subagent และ Tool → ปรับแผน → สังเคราะห์คำตอบพร้อมอ้างอิง
  • เพิ่ม Skill, MCP และ API ใหม่ผ่าน Registry ได้โดยไม่ต้องแก้ไขตัว Agent
  • ทุกคำตอบอ้างอิงกลับไปยังบทความต้นทางใน ThaiJO และฐานข้อมูลสากล
02 · FLAGSHIP

Research Assistant

  • ส่งต่อคำถามไป Deep Research เมื่อต้องการรายงานเชิงลึก หรือบันทึกคำตอบไว้ใน Workspace

03 · AUTHORS & EDITORS

Reference Extraction & Validation

อัปโหลด PDF หรือวางรายการอ้างอิง ระบบจะแยกโครงสร้าง (ผู้แต่ง ปี ชื่อเรื่อง วารสาร DOI) รองรับรูปแบบการอ้างอิงภาษาไทยทั้ง APA และ Vancouver รวมถึงปี พ.ศ. แล้วตรวจสอบกับ ThaiJO และ Crossref ว่ามีอยู่จริง ถูกต้อง และไม่ถูกถอน (retracted) ก่อนส่งถึงบรรณาธิการ

  • แยกรายการอ้างอิงจาก PDF, DOCX หรือข้อความที่วาง
  • ตรวจ DOI, ปี, ชื่อวารสาร และสถานะการถอนบทความ
  • ช่วยบรรณาธิการคัดกรองบทความก่อนส่งผู้ประเมิน

05 · OUTREACH

Paper Explainer

แปลงบทความใน ThaiJO เป็นหน้าเล่าเรื่องแบบเลื่อนอ่าน (scrollytelling) พร้อมแอนิเมชัน Manim ที่ AI สร้างให้สำหรับสมการและแนวคิดสำคัญ ช่วยให้นักศึกษาและสาธารณะเข้าใจงานวิจัยได้ง่ายขึ้น และเพิ่มการมองเห็นของงานวิจัยไทย

  • วางลิงก์บทความจาก ThaiJO แล้วได้หน้าเล่าเรื่องพร้อมแชร์ทันที

  • ใช้สื่อสารงานวิจัยสู่สาธารณะ และเป็นสื่อการสอนในมหาวิทยาลัย

How it works · วิธีทำงาน

สี่ขั้นตอนจากคำถามถึงคำตอบที่ตรวจสอบได้

01

เข้าสู่ Workspace

ใช้บัญชี ThaiJO หรือ ORCID ระบบดึงบริบทของคุณ เช่น สาขา บทความที่เคยตีพิมพ์ และวารสารที่สังกัด

02

ถาม หรือเลือกเครื่องมือ

พิมพ์คำถามเป็นภาษาไทยหรืออังกฤษ หรือเลือกเครื่องมือเฉพาะทาง เช่น Reference Extraction & Validation

03

Agent วางแผนและเรียกใช้เครื่องมือ

Orchestrator แตกคำถามเป็นงานย่อยให้ Subagent เรียก Skill และ MCP ผ่าน TCI MCP Gateway ปรับแผนเมื่อข้อมูลไม่พอ และแสดงทุกขั้นตอนให้เห็น

04

ได้คำตอบพร้อมอ้างอิง

ทุกข้อความลิงก์กลับไปยังบทความต้นทางใน ThaiJO หรือฐานข้อมูลสากล ส่งออกเป็นรายงาน BibTeX หรือ RIS หรือบันทึกไว้ใน Workspace
